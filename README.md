# Click Rush - 60 Second Click Challenge

Challenge your speed in ClickRush! Click as many times as possible in 60 seconds, track your scores, and compete on global, daily, and weekly leaderboards

## Tech Stack

Frontend: Next.js
Backend: Express.js

## Installation

1. Clone the repo:

```bash
git clone https://github.com/azeemuddinaziz/click-rush.git
```

2. Setup Backend

Install dependencies

```bash
cd server
pnpm i
```

Setup Environment Variables

```bash
DATABASE_URL="your-postgres-db-url"
JWT_SECRET="your-jwt-secret"
```

Run the server

```bash
pnpm dev
```

Server will be live at http://localhost:3001

3. Setup Frontend

Install dependencies

```bash
cd client
pnpm i
```

Run the server

```bash
pnpm dev
```

Server will be live at http://localhost:3000
